# CivicLens

## Overview

CivicLens is a backend data integration and analytics platform built with Java and Spring Boot. It ingests
public municipal datasets, transforms them into a unified relational model, and exposes REST APIs that
allow users to explore trends, statistics, and insights across city data. The project is designed to
demonstrate backend software engineering principles, including layered architecture, data modeling,
RESTful API design, and scalable data ingestion.

## Motivation

I created CivicLens to strengthen my backend engineering skills while learning Spring Boot and enterprise
application development. Rather than building a traditional CRUD application, I wanted to design a
system that works with real-world datasets and demonstrates data ingestion, transformation, persistence,
and analytics.

## Current Status

🚧 CivicLens is currently under active development.

The initial milestone focuses on designing the system architecture, establishing the project structure,
and building the backend foundation using Spring Boot and PostgreSQL.
